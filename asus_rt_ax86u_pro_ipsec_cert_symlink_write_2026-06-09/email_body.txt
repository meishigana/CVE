Subject: CVE Request: ASUS RT-AX86U Pro authenticated IPsec certificate archive symlink traversal arbitrary file write

Hello,

I would like to request a CVE ID for an authenticated arbitrary file write vulnerability in ASUS RT-AX86U Pro firmware 3.0.0.6.102_37436.

Summary:

The web endpoint `upload_server_ipsec_cert.cgi` handles IPsec server certificate archive uploads. The endpoint reaches `libwebapi.so!upload_server_ipsec_cert_cgi`, which extracts `/tmp/server_ipsec_file/server_ipsec.tgz` into `/tmp/server_ipsec_file` with `system("tar -xzf %s -C %s")`.

The extraction does not prevent archive-contained symbolic links. A crafted archive can create a symlink inside the extraction directory and then write a subsequent archive member through the symlink outside `/tmp/server_ipsec_file`. In the verified PoC, the archive contains `linkout -> /tmp` followed by `linkout/asus_http_upload_symlink_write`, resulting in attacker-controlled content being written to `/tmp/asus_http_upload_symlink_write`.
